Machine Learning

This module introduces machine learning with a practical approach, building from the underlying mathematics to a framework of learning models, then through the main paradigms and algorithms with hands-on implementation in software, and closing with the systematic design of a complete application system that uses more than one machine learning component.

This module introduces machine learning with a practical approach, providing hands-on cases of real-world data analytics alongside a conceptual understanding of the theories and practices underneath them.

The material evolves gradually: the underlying mathematical concepts first, then a framework of learning models, then the various paradigms and algorithms — each set out as theory alongside a wealth of practical case implementation with software. The final stage is a systematic approach to designing a complete application system that makes use of more than one component of machine learning.

Data analytics requirements are emphasised throughout, with a systematic approach to machine learning implementation, state-of-the-art models and the latest developments in model deployment.

Team design proposal

Unit 6 · Group C

In progress Due 30 November 2026, 23:55 UK time

Group C is building pricing intelligence for Airbnb hosts on Track 3, Advanced Machine Learning: a self-supervised model learns what an ordinary listing looks like, then flags prices that sit out of line with genuinely comparable properties rather than with the market average, and Neural Architecture Search tests whether a better network shape improves it. My role is Data Preparation and Exploratory Analysis — the cleaned dataset and the feature table the modelling leads build on.

Submission

  • Team report — the group design proposal
  • Individual peer review evaluation

What I contributed

  • Cleaned the AB_NYC_2019 dataset of 48,895 New York City listings: set reviews_per_month to zero where a listing simply had no reviews, and removed only the 11 listings priced at $0, leaving 48,884 records.
  • Kept and flagged extreme values rather than trimming them, since those are the cases the anomaly model exists to detect.
  • Established that price is strongly right-skewed (skewness 19.1), so worked in log transforms, medians and rank-based statistics throughout.
  • Ranked the drivers of price with Kruskal-Wallis tests — room type strongest (ε² = 0.46), then borough (ε² = 0.14) — and chose Spearman over Pearson to capture non-linear monotonic relationships.
  • Found distance to Times Square the strongest numeric association with price (ρ = −0.46), that 86% of hosts hold a single listing, and that about a quarter of listings sit dormant.
  • Showed why price has to be judged against comparable listings: peer comparison on neighbourhood and room type flagged 920 unusual listings (1.9%), of which a flat $1,000 cut-off would have missed 704 — including every one of the 49 underpriced.
  • Delivered the 29-column feature table the modelling leads build on, scaling left to be fitted on the training split only, with handover notes.
